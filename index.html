Article 1: Concepto de Diseño Web Responsivo & Viewport

Diseño Responsivo: Filosofía de desarrollo que busca adaptar las páginas web a los diferentes tamaños de pantalla (PC, Tablet, Smartphone).

Viewport: Área visible de la página en el navegador. Se configura mediante <meta name="viewport" content="width=device-width, initial-scale=1.0"> para evitar escalados no deseados en dispositivos móviles.

Article 2: Media Queries & Componentes de Bootstrap 5

CSS3 Media Queries: Permiten aplicar reglas de estilo según características del dispositivo .

Bootstrap 5: Framework CSS que ofrece contenedores (Containers), sistema de grillas de 12 columnas (Grid System), utilidad Flex, componentes como Navbar y Carousel.
